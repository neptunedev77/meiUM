Exploração e Preparação de DadosData Exploration and Preparation

Antes de escolher um modelo é preciso conhecer os dados: que variáveis existem, como se distribuem, como se relacionam entre si e com o que queremos prever. Este tema percorre essa exploração e a preparação que a acompanha.

3.0.1O pipeline de Machine Learning

Um projeto de ML segue, de forma iterativa, oito etapas:

  1. Definição do problema
  2. Recolha dos dados
  3. Preparação dos dados
  4. Divisão treino / validação / teste
  5. Treino do modelo
  6. Avaliação de candidatos
  7. Deployment
  8. Monitorização

A monitorização fecha o ciclo: quando o desempenho em produção cai, volta-se a etapas anteriores (novos dados, nova preparação, novo modelo). Este tema concentra-se nas etapas 1 a 3.

3.0.2O processo de exploração

  1. Importar o dataset.
  2. Perceber o quadro geral: o que é cada linha, qual é o objetivo, que tipos de variáveis existem.
  3. Preparar: corrigir nomes, duplicados, valores em falta, tipos.
  4. Perceber cada variável (análise univariada).
  5. Estudar as relações entre variáveis (análise multivariada).
  6. Brainstorming: tirar conclusões e formular hipóteses — e, se for preciso, voltar aos passos 4 e 5.
  7. Seguir para um relatório e/ou para a modelação.

3.2.3Operações típicas

df = df.rename(columns={'od280/od315_of_diluted_wines': 'protein_concentration'})

Filtrar é perder dados

Uma condição como a de cima remove todas as linhas que não a cumprem. Antes de filtrar, convém ter uma razão (valor impossível, erro de medição, fora do âmbito do problema) — senão estamos só a deitar fora informação.

Remover colunas? Só quando não trazem informação para o objetivo (identificadores, constantes, texto livre irrelevante). No dataset de vinhos todas as variáveis são medições físico-químicas que podem ajudar a distinguir as castas, por isso não há razão para remover nenhuma.

3.2.4Pôr as variáveis na mesma escala

Min-Max (MinMaxScaler)
\[x' = \frac{x - \min}{\max - \min}\in[0,1]\]
Standardização (StandardScaler)
\[z = \frac{x-\mu}{\sigma}\]
Complemento · quando reescalar

Modelos baseados em distâncias ou em pesos (regressão linear/logística com regularização, k-NN, SVM, redes neuronais) são sensíveis à escala. As árvores de decisão não: só comparam um valor com um limiar. O scaler aprende-se (fit) só nos dados de treino e depois aplica-se (transform) ao teste.

Análise univariadaUnivariate Analysis

Olhar para cada variável isoladamente: que valores toma, com que frequência, e que forma tem a sua distribuição.

3.3.1Contagens e resumo

  • value_counts() conta quantas vezes aparece cada valor; com normalize=True dá proporções. Útil para o target e para variáveis categóricas.
  • describe() resume uma variável numérica.
  • hist() desenha o histograma — a forma mais rápida de ver a distribuição.
df['target'].value_counts(normalize=True)   # proporção de cada classe
df['magnesium'].describe()                   # mean 99.74, std 14.28, min 70, max 162
df['magnesium'].hist()                       # não segue uma curva normal: tem picos e cauda à direita

3.3.2Assimetria e curtose

Duas medidas resumem a forma de uma distribuição:

Assimetria · skewness
  • > 0: cauda à direita — moda < mediana < média.
  • ≈ 0: simétrica — as três coincidem.
  • < 0: cauda à esquerda — média < mediana < moda.
Curtose · kurtosis
  • > 0: leptocúrtica — pico alto, caudas pesadas.
  • ≈ 0: como a normal (mesocúrtica).
  • < 0: platicúrtica — achatada, caudas leves.
Assimetria complemento
\[\text{skew}=\frac{1}{n}\sum\left(\frac{x_i-\bar{x}}{\sigma}\right)^3\]
Curtose (excesso) complemento
\[\text{kurt}=\frac{1}{n}\sum\left(\frac{x_i-\bar{x}}{\sigma}\right)^4-3\]

O "−3" faz com que a normal tenha curtose 0. É esta versão (excesso de curtose) que o pandas devolve com .kurt(); o pandas aplica ainda uma pequena correção para amostras.

No magnésio: df['magnesium'].skew() = 1.10 e .kurt() = 2.10. As duas são maiores do que 1: a distribuição tem cauda à direita e mais valores extremos do que uma normal.

Análise multivariadaMultivariate Analysis

Agora as variáveis em conjunto: como se relacionam umas com as outras e, sobretudo, com o target.

3.4.3Binning (discretização)

No binning (ou bucketing), os dados são agrupados em intervalos (bins) e os valores de cada intervalo são substituídos por um único valor representativo. É uma técnica de pré-processamento, como o tratamento de valores em falta, a formatação, a normalização e a standardização.

O binning é uma técnica de suavização: reduz o ruído dos dados, à custa de perder detalhe.

from sklearn.preprocessing import KBinsDiscretizer

kb = KBinsDiscretizer(n_bins=3, encode='ordinal', strategy='quantile')
df['alcohol_bin'] = kb.fit_transform(df[['alcohol']])
kb.bin_edges_[0]                                  # [11.03, 12.52, 13.48, 14.83]
df.groupby('alcohol_bin')['proline'].mean()       # 0: 537, 1: 710, 2: 985

Com strategy='quantile' cada bin fica com o mesmo número de vinhos (59, 58, 61). Agrupando pelos bins vê-se que mais álcool anda a par de mais prolina.

Complemento · estratégias

'uniform': intervalos com a mesma largura. 'quantile': intervalos com o mesmo número de pontos. 'kmeans': intervalos definidos por agrupamento. Com pandas: pd.cut (larguras) e pd.qcut (quantis).

3.4.4Numérica vs. categórica: boxplots

A melhor forma de ver a relação entre uma variável numérica e uma categórica é um boxplot por categoria (sns.catplot(x='target', y='proline', kind='box', data=df)). Se as caixas das classes quase não se sobrepõem, a variável separa bem as classes.

  • proline: a caixa da classe 0 fica muito acima das outras duas.
  • flavanoids: classe 0 estável perto de 3, classe 2 perto de 0.8 — as três caixas mal se tocam.

Boxplots de uma só variável (sns.boxplot(y=df['color_intensity'])) servem para detetar outliers (tema 1, critério de 1.5·IQR).

Para ver se uma variável segue aproximadamente uma distribuição normal (gaussiana), desenha-se o histograma com a densidade estimada por cima: sns.histplot(df['alcohol'], kde=True).

3.4.5Duas numéricas e a classe: dispersão

sns.scatterplot(x='proline', y='flavanoids', hue='target', data=df) mostra duas variáveis ao mesmo tempo, com uma cor por classe. Aqui as três castas formam grupos quase separados: a classe 0 tem prolina alta e flavonoides perto de 3; a classe 2 tem flavonoides baixos; a classe 1 tem prolina baixa. Só com estas duas variáveis já se distingue quase tudo.

3.4.6Matriz de correlação

sns.heatmap(df.corr(), annot=True, vmin=-1, vmax=1) mostra a correlação de todos os pares de uma vez.

  • alcohol × proline = 0.64: mais álcool, mais prolina.
  • flavanoids × total_phenols = 0.86: muito redundantes — dizem quase o mesmo.
  • Flavonoides, fenóis totais, od280/od315 e prolina têm correlação negativa com o número da classe: são altos na classe 0 e baixos na classe 2.
Cuidado com a correlação com o target

A classe é categórica: 0, 1 e 2 são rótulos, não quantidades. A correlação com target só tem leitura porque, neste dataset, as variáveis variam de forma ordenada entre as classes. Para variáveis categóricas, os boxplots e o groupby são mais fiáveis.

3.4.7Análise crítica

No fim da exploração, responde-se às perguntas que orientam a modelação:

Que características definem os diferentes tipos de vinho?

Classe 0: muito álcool, prolina alta, flavonoides altos. Classe 1: pouco álcool, cor clara, prolina baixa. Classe 2: flavonoides muito baixos, cor intensa, matiz (hue) baixo.

Qual é o componente mais importante?

Os flavonoides são a variável mais associada à classe (|r| = 0.85) e as suas caixas por classe quase não se sobrepõem. Combinados com a prolina, separam visualmente as três castas. Um modelo confirmaria esta intuição com a importância das features.

Σ.2Armadilhas frequentes

  • Filtrar linhas sem razão clara é deitar fora informação.
  • Skew > 0 é cauda à direita (média > mediana), não à esquerda.
  • Correlação alta entre duas features (ex.: 0.86) significa redundância, não que ambas sejam úteis.
  • Correlação com um target categórico deve ser lida com cuidado; prefere boxplots e groupby.
  • O scaler aprende-se no treino e aplica-se ao teste — nunca o contrário.

Σ.3Perguntas de escolha múltipla

Uma variável tem média 120 e mediana 95. O que é mais provável?

Valores altos raros puxam a média para cima da mediana → cauda à direita, skew > 0.

Uma curtose (excesso) de 2.1 indica…

Curtose > 0 = leptocúrtica: mais valores extremos do que a normal. A curtose não diz nada sobre simetria.

Qual é o gráfico mais adequado para comparar uma variável numérica entre categorias?

O boxplot por categoria mostra mediana, dispersão e outliers de cada grupo lado a lado.

O binning é sobretudo uma técnica de…

Substituir os valores de um intervalo por um representante suaviza o ruído, à custa de perder detalhe.

Duas features têm correlação 0.95. Isto sugere que…

A correlação entre features mede redundância. Não diz nada sobre a relação com o target, nem sobre causalidade.

Com KBinsDiscretizer(n_bins=4, strategy='quantile'), os bins ficam com…

'quantile' corta nos quartis: ~25% dos dados em cada bin. Larguras iguais é 'uniform'.
