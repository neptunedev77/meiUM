Regressão Linear e LogísticaLinear and Logistic Regression

Dois dos modelos mais simples e mais usados de aprendizagem supervisionada: a regressão linear prevê um número, a regressão logística prevê uma classe (através de uma probabilidade).

4.0.1Aprendizagem supervisionada

A escolha do algoritmo depende do tipo de dados e do contexto. Quando temos dados rotulados — sabemos de antemão a resposta certa (o target) para cada exemplo de treino — usamos o paradigma de aprendizagem supervisionada: o modelo aprende a mapear o input X no output y.

Regressão linearLinear Regression

O modelo assume que o target é uma soma pesada das features mais uma constante. Treinar é encontrar os pesos que fazem as previsões ficar o mais perto possível dos valores reais.

4.1.1O modelo

Previsão complemento
\[\hat{y}=\beta_0+\beta_1x_1+\beta_2x_2+\dots+\beta_px_p\]
  • \(\beta_0\) é a ordenada na origem (intercept_): a previsão quando todas as features valem 0.
  • \(\beta_1,\dots,\beta_p\) são os coeficientes (coef_): um por feature.
  • O treino escolhe os β que minimizam o MSE nos dados de treino (método dos mínimos quadrados).

4.1.2Interpretar os coeficientes

Cada coeficiente lê-se assim: mantendo todas as outras features fixas, aumentar essa feature em 1 unidade está associado a uma variação de β no target.

No exemplo das casas, os dados foram gerados com a fórmula preço = 50 + 2·área + 10·quartos − 0.8·idade − 3·distância + ruído (preço em milhares de €). O modelo recupera-a quase exatamente:

FeatureVerdadeiroEstimadoLeitura
área (m²)2.02.02+1 m² → +2 020 €
quartos1010.80+1 quarto → +10 800 €, à mesma área
idade (anos)−0.8−0.75+1 ano → −750 €
distância ao centro (km)−3.0−2.98+1 km → −2 980 €
intercept5043.91sem significado prático (casa de 0 m²)
Associação, não causa

"Está associado a" não é "causa". Além disso, o tamanho de um coeficiente depende das unidades da feature: um coeficiente grande não quer dizer uma feature importante (o coeficiente do rendimento médio em € é minúsculo porque 1 € é muito pouco).

4.1.3O fluxo completo

  1. Explorar: info(), describe(), pairplot, histograma do target, heatmap das correlações. No exemplo, o preço correlaciona 0.89 com a área.
  2. Escolher X e y: o target é o preço. Colunas não numéricas ou irrelevantes (ex.: a morada) ficam de fora.
  3. Dividir treino/teste e confirmar que o target tem uma distribuição parecida nos dois (histogramas de y_train e y_test).
  4. Treinar e ler intercept_ e coef_.
  5. Prever e analisar: gráfico real vs. previsto (pontos perto da diagonal = bom) e histograma dos resíduos (deve parecer uma normal centrada em 0).
import numpy as np, pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(0); n = 1000
area = rng.normal(120, 30, n).clip(40, 250)
quartos = np.round(area / 30 + rng.normal(0, 0.7, n)).clip(1, 8)
idade = rng.uniform(0, 60, n); dist = rng.uniform(0.5, 25, n)
preco = 50 + 2*area + 10*quartos - 0.8*idade - 3*dist + rng.normal(0, 25, n)
df = pd.DataFrame({'area': area, 'quartos': quartos, 'idade': idade, 'dist_centro': dist, 'preco': preco})

X, y = df.drop(columns='preco'), df['preco']
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

lm = LinearRegression().fit(X_train, y_train)
lm.intercept_                                            # 43.91
pd.DataFrame(lm.coef_, X.columns, columns=['Coefficient'])   # 2.02, 10.80, -0.75, -2.98
predictions = lm.predict(X_test)

Avaliar uma regressãoRegression Evaluation Metrics

As três métricas mais usadas são as do tema 2: MAE, MSE e RMSE. Aqui fica a comparação prática entre elas.

MétricaPorque se usaCasas (teste)
MAEA mais fácil de perceber: é o erro médio.19.83
MSEMais popular do que o MAE porque "castiga" os erros grandes.580.58
RMSEAinda mais popular: castiga erros grandes e está nas unidades do target.24.10

Todas são funções de perda (loss functions): o objetivo é minimizá-las. No exemplo, o modelo erra em média cerca de 20 mil € (MAE), e o RMSE de 24 mil € coincide com o ruído de desvio padrão 25 que pusemos nos dados — não há muito mais a ganhar.

from sklearn import metrics
print('MAE:', metrics.mean_absolute_error(y_test, predictions))        # 19.83
print('MSE:', metrics.mean_squared_error(y_test, predictions))         # 580.58
print('RMSE:', metrics.root_mean_squared_error(y_test, predictions))   # 24.10
Complemento · R²

O coeficiente de determinação \(R^2 = 1 - \frac{\sum(y-\hat{y})^2}{\sum(y-\bar{y})^2}\) diz que fração da variação do target o modelo explica: 1 é perfeito, 0 é tão bom como prever sempre a média. Aqui, metrics.r2_score(y_test, predictions) = 0.901. É também o que lm.score(X_test, y_test) devolve.

Regularização: regressão linear vs. LASSORegularization

A regularização acrescenta uma penalização à função objetivo durante o treino, para evitar overfitting e melhorar a generalização. A ideia é desencorajar o modelo de se ajustar demasiado aos dados de treino, o que o faria falhar em dados novos.

4.3.1LASSO

Função objetivo do LASSO complemento
\[\min_\beta\ \underbrace{\frac{1}{2n}\sum_{i}(y_i-\hat{y}_i)^2}_{\text{erro}}\ +\ \alpha\underbrace{\sum_{j}\lvert\beta_j\rvert}_{\text{penalização L1}}\]
  • O hiperparâmetro alpha controla a força da penalização: alpha=0 é a regressão linear normal; quanto maior, mais os coeficientes encolhem.
  • A penalização L1 tem uma propriedade especial: põe coeficientes exatamente a zero. O LASSO faz, por isso, seleção de features automática.

4.3.2A experiência: features de puro ruído

Acrescentam-se ao dataset duas colunas de números aleatórios (ruido1, ruido2), que não têm nada a ver com o preço, e compara-se a regressão linear com o LASSO:

df['ruido1'] = rng.integers(1, 10, n)        # aleatório, sem relação com o preço
df['ruido2'] = rng.integers(10, 100, n)

lin_reg = LinearRegression().fit(X_train, y_train)

Standardizar antes de regularizar

A penalização trata todos os coeficientes por igual, mas o seu tamanho depende das unidades: um coeficiente "grande" pode só refletir uma feature em unidades pequenas. Com features em escalas muito diferentes, o LASSO regulariza mal. Standardizando primeiro (StandardScaler), basta um α pequeno para eliminar o ruído sem prejudicar o resto (última coluna). Os coeficientes passam a ler-se "por desvio padrão".

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Lasso

lasso = make_pipeline(StandardScaler(), Lasso(alpha=0.5)).fit(X_train, y_train)
lasso[-1].coef_          # [58.72, 13.31, -12.17, -20.35, 0, 0]
Complemento · Ridge

A regressão Ridge usa a penalização L2, \(\alpha\sum\beta_j^2\): também encolhe os coeficientes, mas nunca os põe exatamente a zero. O Elastic Net combina L1 e L2.

Regressão logísticaLogistic Regression

Para classificar não serve uma reta: as previsões têm de ficar entre 0 e 1. A regressão logística calcula a mesma combinação linear da regressão linear e depois "espreme-a" para uma probabilidade.

4.4.1A sigmoide complemento

Combinação linear
\[z=\beta_0+\beta_1x_1+\dots+\beta_px_p\]
Probabilidade da classe 1
\[P(y=1\mid x)=\sigma(z)=\frac{1}{1+e^{-z}}\]
  • z muito positivo → probabilidade perto de 1; z muito negativo → perto de 0; z = 0 → 0.5.
  • A classe prevista é 1 quando a probabilidade passa o limiar (0.5 por omissão). O predict_proba devolve as probabilidades; o predict devolve já a classe.
  • O treino escolhe os β que minimizam o log-loss (entropia cruzada), que castiga muito as previsões confiantes e erradas.

4.4.2Coeficientes

Um coeficiente positivo aumenta a probabilidade da classe 1 quando a feature sobe; um negativo diminui-a. A leitura exata é em termos de odds: +1 unidade multiplica as odds \(P/(1-P)\) por \(e^{\beta}\). complemento

Preparar os dados para o modeloExploratory Data Analysis · Data Preprocessing

A regressão logística (como a linear) só aceita números e não aceita valores em falta. Antes de treinar é preciso tratar das duas coisas.

4.5.1Ver onde faltam dados

Um mapa de calor de df.isnull() (sns.heatmap(df.isnull(), cbar=False)) mostra cada valor em falta como um traço. A decisão depende da quantidade:

SituaçãoExemploO que fazer
Falta uma fração pequena (ex.: ~20%)idade dos passageiros de um navioImputar: preencher com um valor razoável.
Falta quase tudonúmero da cabineRemover a coluna ou substituí-la por uma feature mais simples, como "cabine conhecida: 1 ou 0".
Faltam poucas linhas2 portos de embarque em faltaRemover essas linhas (dropna).

4.5.2Imputar por grupo

Preencher todas as idades em falta com a média global é a solução mais simples. Melhor: usar a mediana do grupo a que a pessoa pertence, se a idade variar entre grupos — por exemplo, passageiros de 1.ª classe tendem a ser mais velhos (um boxplot da idade por classe mostra-o).

df = pd.DataFrame({'Pclass': [1, 1, 1, 1, 3, 3, 3, 3, 3],
                   'Age':    [38, 35, None, 54, 22, 26, None, 35, 2]})

df.groupby('Pclass')['Age'].median()            # 1: 38.0   3: 24.0
df['Age'] = df['Age'].fillna(df.groupby('Pclass')['Age'].transform('median'))
# a idade em falta da 1.ª classe passa a 38, a da 3.ª classe passa a 24

transform('median') devolve, para cada linha, a mediana do seu grupo — com o mesmo tamanho da coluna original, pronta para o fillna.

4.5.3Variáveis categóricas → dummies

pd.get_dummies transforma uma coluna categórica em colunas 0/1, uma por categoria. Com drop_first=True remove-se uma delas, porque é redundante: se não é Q nem S, é C.

EmbarkedQS

sex = pd.get_dummies(df['Sex'], drop_first=True)          # uma coluna: male
embark = pd.get_dummies(df['Embarked'], drop_first=True)  # duas colunas: Q, S
df = pd.concat([df.drop(columns=['Sex', 'Embarked']), sex, embark], axis=1)
Complemento · porquê drop_first

Com todas as colunas, a soma das dummies é sempre 1 — igual à constante β₀. Isso torna os coeficientes de modelos lineares instáveis (multicolinearidade perfeita). Remover uma categoria resolve; os coeficientes passam a ler-se "em relação à categoria removida".

Treinar: solvers e avaliaçãoLogistic Regression solvers

Ao contrário da regressão linear, a logística não tem uma fórmula fechada: os coeficientes encontram-se por um algoritmo de otimização iterativo, o solver.

4.6.1Escolher o solver

  • Para datasets pequenos, liblinear é uma boa escolha; sag e saga são mais rápidos para datasets grandes.
  • Para problemas multiclasse, só newton-cg, sag, saga e lbfgs otimizam a perda multinomial; liblinear fica limitado a esquemas um-contra-todos (one-vs-rest).
SolverPenalizações suportadas
lbfgs (omissão)L2, nenhuma
newton-cgL2, nenhuma
liblinearL1, L2
sagL2, nenhuma
sagaElastic Net, L1, L2, nenhuma

Hiperparâmetros principais: penalty, C (o inverso da força da regularização: C pequeno = mais regularização), solver, max_iter, random_state.

from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_breast_cancer

X, y = load_breast_cancer(return_X_y=True); y = 1 - y        # 1 = maligno
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

logmodel = make_pipeline(StandardScaler(), LogisticRegression(solver='lbfgs', random_state=42))
logmodel.fit(X_train, y_train)
predictions = logmodel.predict(X_test)

  • Uma linha por classe: precision, recall e F1 calculados como se essa classe fosse a "positiva".
  • support: quantos exemplos reais dessa classe há no teste (108 benignos, 63 malignos).
  • macro avg: média simples das classes — cada classe pesa o mesmo.
  • weighted avg: média pesada pelo support — as classes maiores pesam mais.

Com classes desequilibradas, um macro avg muito abaixo do weighted avg indica que a classe pequena está a ser mal prevista.

Σ.2Armadilhas frequentes

  • A regressão logística é de classificação, apesar do nome.
  • Coeficiente grande ≠ feature importante: depende da escala.
  • Regularizar sem standardizar penaliza as features de forma desigual.
  • Em LogisticRegression, C grande = menos regularização.
  • ConvergenceWarning: standardiza ou aumenta max_iter.
  • Dummies com todas as categorias criam redundância; usa drop_first=True em modelos lineares.

Σ.3Perguntas de escolha múltipla

Num modelo de preços, o coeficiente de "quartos" é 10.8 (milhares de €). Isto significa que…

É uma associação, condicionada às outras features. Não prova causalidade.

O que distingue o LASSO da regressão linear normal?

A penalização α·Σ|β| encolhe os coeficientes e anula os menos úteis.

Aumentar o alpha do LASSO…

α maior = penalização mais forte. Com α demasiado grande, até as features úteis desaparecem e o erro sobe.

Uma regressão logística dá z = 0 para uma amostra. A probabilidade da classe 1 é…

σ(0) = 1/(1 + e⁰) = 0.5: a amostra está exatamente na fronteira de decisão.

Num problema multiclasse com perda multinomial, que solver não serve?

liblinear só faz esquemas um-contra-todos (one-vs-rest).

No classification_report, o "support" de uma classe é…

Support = quantos exemplos daquela classe existem em y_test. É o peso usado no weighted avg.

80% dos valores de uma coluna estão em falta. A abordagem mais razoável é…

Imputar 80% dos valores inventa dados; remover essas linhas destrói o dataset. O indicador preserva a pouca informação que existe.
