Ensemble LearningEnsemble Learning

Em vez de procurar o melhor modelo, combinar vários. Se os modelos erram em sítios diferentes, os erros compensam-se e o conjunto (o ensemble) é mais estável e muitas vezes mais exato do que cada um sozinho.

7.0.1As quatro famílias

Max voting

Vários modelos votam; ganha a classe mais votada (ou a de maior probabilidade média).

Bagging

Muitos modelos iguais, cada um treinado numa amostra diferente dos dados; faz-se a média. Random Forest.

Boosting

Modelos treinados em sequência, cada um a corrigir os erros dos anteriores. Gradient Boosting, XGBoost.

Stacking

Modelos diferentes cujas previsões são combinadas por outro modelo (o meta-learner).

Complemento · porque funciona

Se cada modelo acerta 70% das vezes e os erros fossem independentes, a maioria de 5 modelos acertaria cerca de 84%. Na prática os erros são correlacionados (os modelos veem os mesmos dados), por isso o ganho é menor — e daí o esforço do bagging e das Random Forests em diversificar os modelos.

⌁Mapa do tema

Exemplo usado

load_breast_cancer (1 = maligno), dividido 70/30 de forma estratificada. Três modelos simples servem de base de comparação: uma árvore de decisão com max_depth=2, uma regressão logística (com standardização) e uma Random Forest.

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, y = load_breast_cancer(return_X_y=True); y = 1 - y
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42, stratify=y)

dt_model = DecisionTreeClassifier(max_depth=2, random_state=42)
lr_model = make_pipeline(StandardScaler(), LogisticRegression(random_state=42))
rf_model = RandomForestClassifier(random_state=42)

results = {}
for name, m in [('DT', dt_model), ('LogR', lr_model), ('RF', rf_model)]:
    results[name] = m.fit(X_train, y_train).score(X_test, y_test)   # 0.906, 0.971, 0.965

Baseado nas aulas de DAA (Ensemble Learning). Caixas e etiquetas complemento vão além da matéria dada na aula.

Max votingMajority / Hard Voting · Soft Voting

Treinam-se vários modelos, cada um faz uma previsão para cada amostra e "vota". Só a classe com mais votos entra na previsão final.

Hard voting

Cada modelo vota numa classe. Ex.: votos 1, 0, 1 → classe 1.

Soft voting

Faz-se a média das probabilidades. Ex.: P(1) = 0.9, 0.4, 0.7 → média 0.67 → classe 1. Exige modelos com predict_proba.

O parâmetro weights dá mais peso a alguns modelos — por exemplo, weights=[2, 1, 2] conta o voto do primeiro e do terceiro a dobrar.

from sklearn.ensemble import VotingClassifier

hvt_model = VotingClassifier(estimators=[('dt', dt_model), ('lr', lr_model), ('rf', rf_model)],
                             voting='hard', weights=[2, 1, 2])
hvt_model.fit(X_train, y_train)
hvt_model.score(X_test, y_test)

CV no conjunto de teste?

Correr cross_val_score só sobre X_test treina e testa os modelos com uma fração pequena dos dados, o que dá estimativas ruidosas. Para comparar modelos é preferível fazer a validação cruzada sobre todos os dados (ou sobre o treino). complemento

Bagging e Random ForestBootstrap AGGregating

BAGGing (Bootstrap AGGregating) cria várias árvores de decisão a partir do mesmo dataset e combina-as calculando a média das suas previsões (ou o voto da maioria, em classificação).

7.2.1Bootstrap: dados diferentes para cada modelo

Se todas as árvores fossem treinadas com os mesmos dados, seriam iguais e a média não ajudaria. O bagging dá a cada uma uma amostra bootstrap: N elementos tirados ao acaso com reposição dos N originais.

Intuição

Uma árvore profunda tem variância alta: muda muito com pequenas alterações nos dados. A média de muitas árvores ligeiramente diferentes cancela essas oscilações e reduz a variância, sem aumentar muito o bias.

7.2.2Bagging no scikit-learn

BaggingClassifier(estimator=None, n_estimators=10, *, max_samples=1.0, max_features=1.0,
                  bootstrap=True, bootstrap_features=False, oob_score=False, random_state=None)

Para escolher n_estimators usa-se um GridSearch com StratifiedShuffleSplit — outra forma de dividir os dados: faz várias divisões treino/teste aleatórias independentes (como hold-outs repetidos), mantendo a proporção de classes.

from sklearn.model_selection import StratifiedShuffleSplit, GridSearchCV
from sklearn.ensemble import BaggingClassifier

sss = StratifiedShuffleSplit(n_splits=10, test_size=0.2, random_state=42)
bg_dt_model = BaggingClassifier(estimator=dt_model, bootstrap=True, random_state=42)
grid_bg = GridSearchCV(bg_dt_model, {'n_estimators': [10, 40, 60, 80, 100, 160]}, cv=sss)
grid_bg.fit(X_train, y_train)
grid_bg.best_params_                       # {'n_estimators': 40}
grid_bg.best_estimator_.score(X_test, y_test)   # 0.947   (uma só árvore: 0.906)

O mesmo tipo de árvore (profundidade 2), mas 40 em vez de uma: de 0.906 para 0.947.

7.2.3Random Forest

Uma Random Forest é bagging de árvores com um ingrediente extra: em cada divisão, cada árvore só pode escolher entre um subconjunto aleatório de features (max_features='sqrt' por omissão). As árvores ficam ainda mais diferentes umas das outras, o que torna a média mais eficaz. complemento

RandomForestClassifier(n_estimators=100, *, criterion='gini', max_depth=None, min_samples_split=2,
                       min_samples_leaf=1, max_features='sqrt', bootstrap=True, oob_score=False,
                       random_state=None, class_weight=None, ccp_alpha=0.0, max_samples=None)
Complemento · out-of-bag

Cada árvore deixa de fora cerca de 37% dos dados. Com oob_score=True, cada observação é avaliada só pelas árvores que não a viram — uma estimativa de desempenho "grátis", sem precisar de um conjunto de validação.

BoostingGradient Boosting · XGBoost

O boosting acrescenta membros ao ensemble sequencialmente: cada novo modelo foca-se em corrigir as previsões dos anteriores, e o resultado final é uma média pesada das previsões.

7.3.2Gradient Boosting

No Gradient Boosting, cada nova árvore aprende os erros que ainda restam (os resíduos, ou mais geralmente o gradiente da perda) e soma-se ao modelo, multiplicada por um fator pequeno — a learning_rate. complemento

GradientBoostingClassifier(*, loss='log_loss', learning_rate=0.1, n_estimators=100, subsample=1.0,
                           max_depth=3, random_state=None, ...)
  • n_estimators: número de árvores (etapas).
  • learning_rate: quanto cada árvore contribui. Valores menores precisam de mais árvores, mas generalizam melhor — os dois afinam-se em conjunto.
  • max_depth: profundidade de cada árvore (pequena; com 1, cada árvore é um único "toco").
from sklearn.ensemble import GradientBoostingClassifier
gbc_model = GradientBoostingClassifier(random_state=42).fit(X_train, y_train)
gbc_model.score(X_test, y_test)            # 0.965

7.3.3XGBoost

XGBoost é uma biblioteca de gradient boosting otimizada (rápida, com regularização incorporada e suporte para valores em falta), muito usada em competições de dados tabulares. Não vem com o scikit-learn: instala-se com pip install xgboost ou conda install -c conda-forge xgboost, e tem a mesma interface (fit, predict, score).

from xgboost import XGBClassifier
xgb_model = XGBClassifier(max_depth=2, objective='binary:logistic', random_state=42)
xgb_model.fit(X_train, y_train)
xgb_model.score(X_test, y_test)            # 0.977
Escolher o objective certo

Em classificação binária usa-se objective='binary:logistic' (o valor por omissão do XGBClassifier). 'reg:squarederror' é o objetivo de regressão e não deve ser usado para classificar.

StackingStacking Classifier

O stacking treina modelos de tipos diferentes no mesmo dataset e usa um outro modelo — o meta-learner — para aprender a melhor forma de combinar as suas previsões.

  1. Os modelos base (ex.: árvore, regressão logística, Random Forest) fazem previsões.
  2. Essas previsões tornam-se as features de um novo dataset.
  3. O meta-learner (muitas vezes uma regressão logística) aprende, a partir delas, a previsão final — por exemplo, a confiar mais num modelo do que noutro.
from sklearn.ensemble import StackingClassifier

estimators = [('dt', dt_model), ('lr', lr_model), ('rf', rf_model)]
st_model = StackingClassifier(estimators=estimators, final_estimator=LogisticRegression())
st_model.fit(X_train, y_train)
st_model.score(X_test, y_test)             # 0.977
Complemento · porque o stacking usa CV internamente

Se o meta-learner aprendesse com previsões feitas sobre os mesmos dados em que os modelos base treinaram, veria previsões demasiado boas (os modelos já conhecem as respostas). Por isso o StackingClassifier gera essas previsões com validação cruzada (cv, 5 folds por omissão).

7.5.1Qual foi o melhor? Quais vale a pena afinar?

Pensa primeiro, depois abre
  • As diferenças entre os melhores são pequenas (0.95–0.97) e menores do que o desvio padrão da CV (≈ 0.02). Num só hold-out, a ordem entre eles podia trocar com outra semente.
  • O ensemble mais simples que mais ganhou foi o bagging: transformou uma árvore fraca (0.905) em 0.940.
  • A regressão logística sozinha empata com o stacking: neste dataset as classes separam-se quase linearmente, e um modelo simples já chega perto do limite. Um ensemble não é automaticamente melhor.
  • Vale a pena afinar os modelos com hiperparâmetros mais sensíveis e resultados promissores: XGBoost/Gradient Boosting (learning_rate, n_estimators, max_depth) e Random Forest (max_features, min_samples_leaf).
Comparar com o quê

Para escolher entre modelos usa-se a validação cruzada (média e desvio), não uma única divisão treino/teste. O conjunto de teste fica para confirmar, no fim, o modelo escolhido.

Σ.2Armadilhas frequentes

  • Soft voting exige modelos com predict_proba.
  • Bagging de modelos iguais sem diversidade não ajuda; é o bootstrap que cria a diversidade.
  • Boosting com demasiadas árvores (ou learning_rate alto) pode fazer overfitting.
  • XGBoost para classificar: objective='binary:logistic', não um objetivo de regressão.
  • Um ensemble não é sempre melhor do que um bom modelo simples — compara com CV.

Σ.3Perguntas de escolha múltipla

Três modelos dão P(classe 1) = 0.9, 0.4 e 0.45. O que preveem o hard e o soft voting?

Votos: 1, 0, 0 → hard dá 0. Média: 0.583 → soft dá 1. O modelo muito confiante pesa mais no soft.

O que significa "bootstrap" no bagging?

Cada modelo recebe uma amostra com reposição: alguns elementos repetem-se, ~37% ficam de fora.

O que distingue uma Random Forest de um bagging de árvores?

A escolha aleatória de features (max_features) torna as árvores mais diferentes entre si.

No boosting, cada novo modelo…

É sequencial: cada modelo aprende o que os anteriores ainda erram.

No stacking, o "meta-learner"…

Aprende a combinar as previsões; a média fixa seria soft voting.

Diminuir a learning_rate de um Gradient Boosting normalmente exige…

Cada árvore contribui menos, por isso são precisas mais etapas para chegar ao mesmo ajuste — mas costuma generalizar melhor.
