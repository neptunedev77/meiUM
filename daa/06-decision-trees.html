Poda de Árvores e Afinação de HiperparâmetrosDecision Tree Pruning and Hyperparameter Tuning

Uma árvore de decisão sem limites continua a dividir até acertar em todos os exemplos de treino — e decora o ruído. Este tema mostra como a limitar (poda) e como escolher os seus hiperparâmetros de forma sistemática.

6.0.1O problema em números

Uma árvore sem restrições, treinada no dataset de tumores:

Folhas

0.901

Perfeita no treino, bem pior em dados novos: overfitting. Uma árvore com apenas 3 níveis e 6 folhas chega a 0.918 no teste — mais simples e melhor.

6.1.2Como a árvore escolhe as divisões complemento

Em cada nó, a árvore experimenta divisões ("feature ≤ limiar") e escolhe a que deixa os nós-filhos mais puros — com uma classe dominante. A impureza mede-se com:

Gini
\[G=1-\sum_k p_k^2\]
Entropia
\[H=-\sum_k p_k\log_2 p_k\]

\(p_k\) é a proporção da classe k no nó. Um nó só com uma classe tem G = H = 0; um nó 50/50 tem G = 0.5 e H = 1. Na prática, os dois critérios dão árvores parecidas.

6.1.3Ver a árvore

from sklearn import tree
from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split

data = load_breast_cancer(); X, y = data.data, 1 - data.target      # 1 = maligno
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42, stratify=y)

dt_model = DecisionTreeClassifier(random_state=42).fit(X_train, y_train)
dt_model.get_depth(), dt_model.get_n_leaves()          # (8, 19)

fig = plt.figure(figsize=(25, 20))
tree.plot_tree(dt_model, max_depth=3, feature_names=data.feature_names)   # desenho (só 3 níveis)
fig.savefig('dt_plot.png')
print(tree.export_text(dt_model, feature_names=list(data.feature_names)))   # versão em texto

Com max_depth=2, o export_text mostra as regras aprendidas:

Dois testes chegam para uma primeira separação: tumores grandes (perímetro > 112.8) são classificados como malignos; nos pequenos, decide a concavidade. Esta legibilidade é a grande vantagem das árvores.

Parâmetros vs. hiperparâmetrosParameters and Hyperparameters

Há valores que o modelo aprende sozinho a partir dos dados e valores que temos de escolher antes do treino. Afinar um modelo é encontrar a melhor configuração dos segundos.

Parâmetro do modelo

Variável de configuração interna, estimada a partir dos dados de treino — não se define à mão.

  • Pesos de uma rede neuronal.
  • Vetores de suporte de uma SVM.
  • Coeficientes de uma regressão (tema 4).
  • Os limiares de cada divisão de uma árvore.
Hiperparâmetro

Variável de configuração externa, definida manualmente. É difícil saber à partida o valor ótimo.

  • Otimizador e learning rate de uma rede neuronal.
  • C e gamma de uma SVM.
  • Medida de qualidade e método de poda de uma árvore.
  • alpha do LASSO.

Classifica cada um:

O max_depth de uma árvore.
Os coeficientes de uma regressão linear.
O C de uma regressão logística.
O limiar "worst perimeter ≤ 112.8" numa árvore treinada.
O learning rate de uma rede neuronal.

Afinação com GridSearchHyperparameter Tuning with GridSearch

Encontrar os hiperparâmetros certos pode ser difícil. A ideia de criar uma grelha de valores e experimentar todas as combinações chama-se GridSearch.

6.3.1Como funciona

  • O scikit-learn traz esta funcionalidade em GridSearchCV (CV = cross validation, tema 2).
  • Recebe o modelo e um dicionário: as chaves são os hiperparâmetros, os valores são as listas de valores a testar.
  • É um meta-estimador: cria um novo estimador que se comporta como o original (tem fit, predict, score).
  • Recomenda-se refit=True e um verbose à escolha (quanto texto mostra durante o processo).

Ao chamar fit:

  1. Para cada combinação da grelha, corre validação cruzada e regista o score médio.
  2. Escolhe a melhor combinação.
  3. Com refit=True, volta a treinar uma vez com essa combinação em todos os dados passados ao fit (sem CV), criando o modelo final.
Quantos treinos?
\[\text{n.º de combinações}\times k\ \text{folds}\ (+1\ \text{refit})\]

6.3.2Exemplo

Uma ideia para a grelha: a árvore completa tem profundidade 8, por isso faz sentido testar profundidades até perto desse valor.

from sklearn.model_selection import GridSearchCV

param_grid_dt = {'criterion': ['gini', 'entropy'], 'max_depth': list(range(1, 11))}
grid_dt = GridSearchCV(DecisionTreeClassifier(random_state=42), param_grid_dt, cv=5, refit=True, verbose=1)
grid_dt.fit(X_train, y_train)          # 20 combinações × 5 folds = 100 treinos (+1 refit)

grid_dt.best_params_                   # {'criterion': 'entropy', 'max_depth': 3}
grid_dt.best_score_                    # 0.932   accuracy média na CV
grid_dt.best_estimator_                # o modelo final, já treinado
grid_dt.score(X_test, y_test)          # 0.918   no teste
Não afines no conjunto de teste

O GridSearch usa só os dados de treino (com CV dentro deles). O teste fica de fora até ao fim, para dar uma estimativa honesta. Se escolhesses os hiperparâmetros a olhar para o teste, essa estimativa ficaria otimista.

Complemento · RandomizedSearchCV

Com muitos hiperparâmetros, a grelha cresce exponencialmente. O RandomizedSearchCV testa só n_iter combinações sorteadas e costuma encontrar uma boa configuração muito mais depressa.

Poda da árvoreDecision Tree Pruning

Podar é substituir uma subárvore inteira por uma folha: se o erro esperado da subárvore for maior do que o de uma única folha, a subárvore sai.

6.4.1Quando e como podar

  • Se um nó fica muito pequeno, não o dividir mais.
  • A poda por erro mínimo (com CV), sem paragem antecipada, é uma técnica eficaz.
  • Construir a árvore completa e trabalhar de trás para a frente, com um teste estatístico em cada etapa.
  • Podar um nó interno e subir a subárvore abaixo dele um nível.
Pré-poda · max_depth

Impede a árvore de crescer: para antes de chegar a uma certa profundidade (ou tamanho de nó).

Pós-poda · ccp_alpha

Deixa a árvore crescer toda e depois corta os ramos que custam mais complexidade do que o que ganham em pureza.

6.4.2Pré-poda: max_depth

max_depth = dt_model.get_depth()           # 8
param_grid_pru = {'max_depth': [d for d in range(1, max_depth + 1)]}
max_depth_gs = GridSearchCV(DecisionTreeClassifier(random_state=42), param_grid_pru).fit(X_train, y_train)
max_depth_gs.best_params_                  # {'max_depth': 4}   0.927 na CV, 0.906 no teste

A CV escolhe 4, embora no teste a profundidade 3 seja ligeiramente melhor (0.918). É normal: com poucas centenas de exemplos, diferenças de 1% estão dentro do ruído. A escolha honesta é a da CV — escolher pelo teste seria usá-lo para treinar.

6.4.3Pós-poda: ccp_alpha

A poda por custo-complexidade (cost complexity pruning) avalia cada subárvore T com complemento:

\[R_\alpha(T)=R(T)+\alpha\,\lvert T\rvert\]

R(T) é a impureza total das folhas e |T| o número de folhas. Com α = 0 fica a árvore completa; à medida que α cresce, compensa cortar ramos, até restar só a raiz. O scikit-learn calcula os valores de α em que cada corte acontece:

path = dt_model.cost_complexity_pruning_path(X_train, y_train)
ccp_alphas = path['ccp_alphas']             # [0, 0.0025, 0.0025, 0.0034, …, 0.0356, 0.3364]

ccp_alpha_gs = GridSearchCV(DecisionTreeClassifier(random_state=42),
                            {'ccp_alpha': list(ccp_alphas[:-1])}).fit(X_train, y_train)
ccp_alpha_gs.best_params_                   # {'ccp_alpha': 0.0080}
best_ccp_alpha_tree = ccp_alpha_gs.best_estimator_     # 6 folhas, profundidade 3, 0.918 no teste

O último α corta tudo até à raiz (um só nó), por isso fica de fora.

Ler o gráfico

À esquerda o modelo é demasiado complexo (overfitting: treino alto, teste mais baixo); à direita é demasiado simples (underfitting: os dois descem). O ponto ótimo está entre os dois — a mesma ideia do compromisso entre bias e variância.

Σ.2Armadilhas frequentes

  • Accuracy de 100% no treino numa árvore é sinal de overfitting, não de sucesso.
  • Escolher hiperparâmetros a olhar para o teste torna a avaliação otimista.
  • Grelhas grandes multiplicam o custo: combinações × folds.
  • α demasiado grande (ou max_depth demasiado pequeno) leva a underfitting.

Σ.3Perguntas de escolha múltipla

Uma grelha com 3 valores de criterion × 8 de max_depth, com cv=5. Quantos treinos faz o GridSearchCV (sem contar o refit)?

3 × 8 = 24 combinações, cada uma treinada 5 vezes = 120.

O que faz refit=True?

Depois de escolher a melhor combinação por CV, treina-a uma vez com todos os dados de treino; fica em best_estimator_.

Qual destas é uma técnica de pós-poda?

ccp_alpha corta ramos de uma árvore já crescida. As outras impedem-na de crescer (pré-poda).

Ao aumentar ccp_alpha, a árvore…

α maior penaliza mais cada folha, logo compensa cortar mais ramos.

Os pesos de uma rede neuronal são…

São estimados a partir dos dados durante o treino.

Um nó tem 50% de cada classe. Qual é o seu índice de Gini?

1 − (0.5² + 0.5²) = 0.5, o máximo para duas classes.
